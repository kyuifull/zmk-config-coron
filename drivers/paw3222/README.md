# PAW3222 ドライバ（同梱版）

Coron V2 のトラックボールに使っている PIXART **PAW3222** 光学センサーのドライバです。

出典: [sekigon-gonnoc/zmk-driver-paw3222](https://github.com/sekigon-gonnoc/zmk-driver-paw3222)（Apache-2.0）
Copyright 2024 Google LLC / Modifications Copyright 2025 sekigon-gonnoc

このリポジトリに**コピーを同梱**しています。`west.yml` からは参照していないので、クローンすればそのままビルドできます。

---

## なぜ同梱しているか

上流のドライバに、**SPI の読み出しが1回失敗するとトラックボールが固まる**問題があるためです。

ドライバは動き検出の割り込みが来ると、いったん割り込みを無効化して 15ms のタイマーでポーリングに切り替えます。ところが読み出しに失敗すると、**割り込みを無効にしたまま、タイマーも再セットせずに** `return` していました。

```c
ret = paw32xx_read_reg(dev, PAW32XX_MOTION, &val);
if (ret < 0) {
    return;        // 割り込みもタイマーも止まったまま
}
```

こうなると誰もセンサーを見に行かなくなり、**基板をリセットするまで復帰しません**。読み出しが失敗するのは稀なので、症状は「たまに突然トラックボールが死ぬ」という再現しにくい形で出ます。

### 変更点

失敗しても止まらないようにしました。

- 読み出しに失敗したら **250ms 間隔でポーリングを継続**する（固まらない）
- 失敗を `LOG_ERR` で記録する（1回目と、以降100回ごと。ログが溢れません）
- 復帰したら `LOG_WRN` で「何回失敗したあとに復帰したか」を出す
- 初期化時に読めた product ID を `LOG_INF` で出す

これで、一時的な読み出し失敗は**一瞬のカクつき**で済むようになります。ログはリポジトリの README の「調子が悪いときの調べ方」で確認できます。

## 配線（Coron V2 の場合）

**2線モード**で使っています。SDIO 1本を読み書き兼用にして、NCS は基板上で GND に直結しています。

| PAW3222 | 接続先 |
|---|---|
| VDD / VDDIO | 3V3（各 0.1µF でデカップリング） |
| GND | GND |
| SCLK | XIAO P0.05 |
| SDIO | XIAO P0.04（双方向1本） |
| MOTSWK (MOTION) | XIAO P0.02（プルアップ、アクティブ Low） |
| NCS | **GND 直結** |

nRF52840 側は `SPIM_MOSI` と `SPIM_MISO` を両方 P0.04 に割り当てています。

NCS が GND 固定なので Zephyr 的には CS ピンが不要ですが、SPI API が CS を要求するため、**どこにも繋がっていない P1.00 をダミー CS** として指定しています。

```dts
&spi0 {
    cs-gpios = <&gpio1 0 GPIO_ACTIVE_LOW>;   /* ダミー。実配線なし */

    trackball: trackball@0 {
        compatible = "pixart,paw3222";
        reg = <0>;
        spi-max-frequency = <2000000>;
        irq-gpios = <&gpio0 2 (GPIO_ACTIVE_LOW | GPIO_PULL_UP)>;
        res-cpi = <608>;
    };
};
```

## 設定できる項目

devicetree のプロパティです。

| プロパティ | 説明 |
|---|---|
| `irq-gpios` | **必須**。MOTION ピン。アクティブ Low |
| `res-cpi` | 解像度。**38 の倍数**で 608〜4826。範囲外だとビルドが止まります |
| `force-awake` | 付けると自動スリープを無効化。反応は良くなりますが電池を食います |
| `power-gpios` | センサーの電源を GPIO で制御する場合。Coron V2 では未使用 |

Kconfig 側は `CONFIG_PAW3222=y` だけです（シールドの `Kconfig.defconfig` で自動的に有効になります）。

### 感度について

`res-cpi` の下限が 608 なので、これ以上 CPI を下げられません。もっと遅くしたい場合は ZMK の入力プロセッサで割ります。

```dts
input-processors = <&zip_xy_scaler 2 3>;   /* 2/3 の速さ */
```

`zip_xy_scaler` は端数を持ち越すので、ゆっくり動かしたときの微小な動きも失われません。

### スリープについて

`force-awake` を付けていないので、センサーは無操作が続くと自動でスリープに入ります。ただし**スリープまでの時間はチップの初期値**です。ドライバは SLEEP1〜3 のレジスタを書いていないので、config からは変更できません。
